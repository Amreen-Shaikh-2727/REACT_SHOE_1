# React Hooks Shopping Cart

A simple shopping cart application built with React and Vite. The project demonstrates React Hooks and basic cart functionality.

## Features

- Display product cards with images and prices.
- Add products to the cart.
- Increase or decrease product quantities.
- Automatically calculate the total price.
- Responsive layout.

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## How to Run

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal.
